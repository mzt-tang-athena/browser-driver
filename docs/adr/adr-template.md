# ADR template

Copy this file, rename it `NNNN-short-title.md` (next free number, keep zero
padding).

Write like this everywhere: short sentences, active voice, plain words. If a
sentence needs a third clause, split it. The five rules live in the global
agent instructions; the short version:

1. Active voice, "we" statements.
2. One idea per sentence.
3. Common verbs (keep, run, copy, move), not fancy ones.
4. Facts over drama: state importance once, plainly.
5. One name per thing, forever.

Example of the voice:
"We migrate ntfy first. ntfy is a single container on the tailnet. That makes
it the safest rehearsal for the pattern."

```markdown
# NNNN. Short title

- **Status:** proposed | accepted | superseded by NNNN
- **Date:** YYYY-MM-DD

## Context

State the situation in plain sentences: what exists, what the problem is,
why now.

## Decision

Say what we decided in one or two sentences. If a plain alternative was
considered and rejected, say so and why in one sentence.

## Consequences

What this makes easier. What it costs or leaves imperfect on purpose.
```
